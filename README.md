# 💻 Cyber Hack: Terminal Matrix

**Cyber Hack** is a cyberpunk logic and sequence-matching game inspired by matrix breaching mechanics in classic RPGs. Built natively using standard HTML5, CSS3, and JavaScript, players extract memory hex blocks under tight time constraints while adhering to alternating row and column pointer locks.

---

## 🌟 Key Features

* **Zero Dependencies:** Pure Vanilla HTML5/CSS3/JavaScript codebase running at optimal browser performance.
* **Procedural Puzzle Engine:** Generates solvable hex matrices with alternating row/column constraints on every run.
* **Authentic CRT Visuals:** Styled with custom CSS scanlines, glowing terminal text, and dynamic buffer state tracking.
* **Time Mechanics:** Speed bonuses reward fast breaches, while buffer overflow results in firewall lockouts.
* **Mobile & Desktop Responsive:** Fully touch-compatible matrix selection.

---

## 🎮 How to Play

1. **Target:** Match the required 3-symbol hex sequence displayed in the top bar.
2. **Selection Rule:**
   * Your 1st pick must come from the active **Row**.
   * Your 2nd pick must come from the active **Column** intersecting your previous selection.
   * Lock constraints alternate continuously between rows and columns.
3. **Buffer Management:** Your sequence must be extracted before filling the 6-slot buffer or running out of time!
